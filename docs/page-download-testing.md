# 选页下载与单张保存测试

下载管理保留「批量队列 / 正在下载 / 已完成」三页。「正在下载」内增加横向的「下载任务 / 单张保存」子 tab，点击切换；左右滑动仍切换外层页面。

## 使用入口

- 图片详情：打开含「翻译漫画 / 翻译整部 / 圈选翻译」的菜单，点击「圈选翻译」下方的「选择多页下载」。
- 作品详情（经典 / V3）：打开「更多」菜单，点击「画质增强 / 智能抠图」下方的「选择多页下载」。
- 快捷方式：详情页长按下载按钮，在分辨率菜单末尾选择「选择多页下载」；大图页长按「保存当前图」直接打开选页网格。单击仍保存当前显示图片，译图行为不变。离线快照和动图菜单不显示选页下载。
- 选页默认勾选当前页，可以选择多页、全选/取消全选、仅当前页、选择未下载页。
- 所选页面使用设置中的默认下载分辨率，进入现有 Manager 页级调度；不会为此创建整作品批量队列记录。
- 「单张保存」显示 ImagePageSaver 的原图保存任务、阶段和错误，提供写盘前取消、失败重试及移除失败记录。开始写盘后不可取消。成功后沿用原有按页下载记录和已完成页，不改 P 数显示。
- 下载任务的工具栏批量暂停、继续、重试和清空不作用于单张保存。没有新增共享图片网络传输的暂停能力。
- 单张原图保存的任务与失败原因保存在应用私有的持久目录。应用启动后自动恢复中断的任务，不必先打开作品页；失败记录保留等待重试。恢复前核对入队后写下且仍可读的完成记录，避免重复落盘。取消、成功和移除失败项均在记录写盘后更新列表。
- 切后台后系统仍可能回收进程，本次保证再次启动时恢复任务，不保证应用关闭期间持续下载，也不新增网络字节级断点续传。译图保存与译图缓存仍沿用原有进程级行为。

## 快速构建

要求 JDK 17+、Android SDK（compileSdk 36），并接受 SDK licenses。Gradle daemon 使用项目既有 JDK 17 配置；首次构建需要联网下载工具链、CMake/NDK 与依赖。

```bash
bash scripts/build-test-apk.sh
bash scripts/build-test-apk.sh --test
bash scripts/build-test-apk.sh --test --install
bash scripts/build-test-apk.sh --abi x86_64
```

默认构建 arm64-v8a 的 GitHub Debug 包，复用增量缓存，不执行 clean 或 release 混淆。APK 与 SHA-256 输出到 `dist/test-apk/`。`--install` 要求 adb 仅连接一台设备。脚本通过 `-PSHAFT_BETA_TEST=true` 使用历史 Beta 包名 `ceui.pixiv.pshaft.beta`，应用名为 `Shaft.beta`，可与原版共存。普通开发 Debug 使用 `ceui.pixiv.cshaft.beta`，Release 使用 `ceui.pixiv.pshaft.beta`。覆盖已有 Beta 安装要求签名相同；沿用本机 keystore 配置或仓库的 `SHAFT_KEYSTORE_*` 签名 Secrets，快速脚本缺少固定签名时停止，避免生成不同的安装签名。

也可进入 GitHub Actions → **Quick test APK** → **Run workflow**，完成后下载 `pixiv-shaft-beta-test-*` artifact。先按 [Beta 固定签名](beta-signing.md) 配置仓库自己的签名 Secrets；不需要官方服务密钥。部分依赖官方凭据的线上功能维持 fork 的原有可用范围。

## 验收场景

1. 在 20P 作品选择第 3、7、12 页，确认只提交这三张；已有同 URL 任务不重复添加。
2. 选择页状态在旋屏后保留，包括手动取消全部后的空选择。
3. 已有本地文件和正在下载的页显示标记，「选未下载」跳过这些页；手动仍可选择重新下载。
4. 慢网时在大图点保存后退出，进入「正在下载 → 单张保存」查看进度；等待阶段取消，不留下保存结果。
5. 保存开始写盘后取消按钮禁用；保存成功后任务移除，并按原有方式显示在已完成页。
6. 断网或不可写目录产生失败，退出再进子 tab 后错误仍保留，重试/移除可以操作。
7. 单张保存与整作品下载同页时继续使用现有 URL 写锁；批量操作不取消保存任务。
8. 深浅主题、窄屏、平板和放大字体检查两个子 tab、长标题、错误文本与选页按钮。
9. 图片详情菜单的「选择多页下载」紧接「圈选翻译」；经典 / V3 作品菜单紧接「智能抠图」，各只有一个入口。翻到非首页后打开，默认勾选当前页；取消后不提交任务，确认只提交选中页。动图和离线快照中不显示该入口。
10. 在大图页发起多张原图保存，退到后台，用 `adb shell am kill ceui.pixiv.pshaft.beta` 模拟后台进程回收，再从桌面打开：任务自动恢复，进度按实际来源重算，未打开下载页也能继续。使用「强行停止」测试时先重新手动启动应用。
11. 断网失败后结束并重新打开应用，失败项和原因仍在；重试后只保留一条任务。取消或移除失败项并等待列表消失，再结束并重开，旧任务不应复活。已写文件并记入完成表、但还没来得及清理队列时结束进程，重开不应重复保存同页。

旧行为限制仍在：写锁按 URL 区分，跨分辨率但指向相同目标文件的情况没有在本次重构。已完成页不据此增加「整作品下载完成」判断。
