## 兼容调整

- 恢复 `ImageLoaderV3.awaitExistingFile(ImageLoadTask, ...)` 的等待接口，保留等待者取消不终止共享看图任务、图源失败正常向调用方传播的契约。
- 续传抓取器实际使用注入的缓存目录进行查询和提交，测试显式提供进度回调；复用同一套提交方法，覆盖缓存命中、206 续传、416 已完成、200 重新开始和断流保留分片。
- 原图保存与抓取在开始前按 URL 保留缓存引用。LRU、手动清理和旧分片清扫跳过仍被使用的 key；保存结束释放引用并重新检查配额。多消费者引用计数，重复释放不影响其他使用者。
- 新增跨流程测试：大图与保存共享原图任务、取消等待者后看图继续、重开后从独立原图磁盘缓存取图，以及清理期间保留保存源。
