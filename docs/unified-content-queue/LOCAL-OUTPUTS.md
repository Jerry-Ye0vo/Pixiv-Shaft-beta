# 简介、备份与旧动图出口

作品简介、已有备份文件和旧动图成品复制提交 local-output 父任务。文本、源文件身份、存储/命名/覆盖策略冻结，私有输入在 COPY 中捕获并校验，再由共享 ArtifactPublisher 发布。已捕获输入和已写 URI 可以独立重试；不会因为原页面关闭就取消。

旧备份的任意 fileWriter 回调在父任务持久化后的 COPY 阶段执行，函数引用在生成后释放。回调本身不能跨进程序列化：如果进程在捕获完整产物前退出，该任务明确失败并提示重新导出；捕获后不再依赖回调或原缓存文件。暂停后同进程继续保留尚未执行的生成器。分享临时文件使用每次独立的子目录和原显示文件名，保留 FileProvider 使用方式，避免下一份备份截断正在分享的临时文件。

源文件预先登记引用，私有副本确认后释放。GIF 缓存的借用以可转交的读引用交给 worker；等待清缓存的 writer 已存在时，worker 使用已有引用，不再等待第二份读许可，避免互相等待。未开始写字节的取消不必为了不存在的临时目录等待 COPY。暂停释放原缓存引用，若用户随后清掉尚未捕获的源文件，恢复会明确报告输入缺失，用户可重新导出。

旧自动保存 GIF 记录在 Manager 恢复时按原 UUID 移交：先等待新父任务持久化，再退役旧 ZIP 日志。已经失败、暂停或取消的父任务及其冻结内容不因旧日志重放而复活。迁移记录等待用户继续；旧记录没保存的格式/目录信息在迁移时固定。已在跑的旧 ZIP 保存也在完成前移交；仅播放的旧 ZIP 仍使用共享 NETWORK，并在清缓存等待时通过非阻塞读引用退出重试。

父任务新增初始 PAUSED/FAILED 和“复用既有持久意图”选项，数据库格式不变。还修复了入队尚未持久化时点暂停会被当作取消的问题；请求先持久化为暂停，再等待继续。已下载、查重和小说历史表保持。

本轮新增16项专项，预计406项；以当前提交 Actions 实际结果为准。完整小说系列组恢复、全局优先调度、统一列表及最终构建/报告仍在继续。
