# 模型下载与导入

Rembg、RIFE、漫画文字检测、OCR 和翻译模型通过同一 ModelDownloadManager facade 提交持久父任务。页面关闭仅停止观察；任务由进程持有。普通图片缩略图和小说阅读不经过这里。

- 请求保存版本、模型目录、必需文件、操作、代理后的来源和超时。网络下载、SAF 导入、安装、删除分别领取共享 NETWORK/COPY 许可；父任务不占物理池等待下一阶段。
- 使用每个父任务独立的私有 ZIP/断点/暂存/备份目录。网络取消会关闭 OkHttp Call，保留有校验器的有效前缀。完整输入以长度和 SHA-256 检查点复用。
- 必需文件非空、ZIP 路径/重复条目/CRC/展开大小检查发生在旧模型移动之前。目录换入失败尝试回滚；旧目录在父任务提交完成回执后才清理。
- 目录内的安装回执记录父任务、冻结请求和文件摘要，进程在目录换入后退出时可以离线核实结果。文件系统和 SQLite 并非同一原子事务，不宣称严格一次执行。
- 同目标的取消收尾与下一次意图串行；已经开始最终提交时，删除意图持久等待该提交结束。关闭页面不会删除旧模型，显式取消不能撤销已提交的模型。
- 老模型目录和模型 enum API 保留；现有打包内置 Rembg 的 ready override 保留。非内置模型必须是非空文件。没有对 ONNX 数值正确性或各手机推理性能作额外保证。
- SAF 尝试取得持久读取授权；provider 不支持、授权丢失或源文档消失时任务明确失败，已安装模型保留。源输入捕获后恢复使用私有副本。现阶段授权跟随 Android 文档授权管理，不主动撤销可能被其它功能共用的授权。
- 手动许可仅放行本模型 family；进程冷恢复服从自动策略。离开 Wi-Fi 撤销这一会话的模型手动许可并重新评估；暂停不会因策略变化自动恢复。

回归包含真实 SQLite、MockWebServer、文件系统与暂停/续传；安装结果的 Gson schema 另在 minified release 的 API35 仪器测试覆盖。物理手机、存储耗尽、文档 provider 撤权和原始进程退出仍需最终真机验收。
