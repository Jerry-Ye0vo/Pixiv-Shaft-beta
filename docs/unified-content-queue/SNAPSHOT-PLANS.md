# 快照生成父任务

正式和自动快照使用持久 snapshot 父任务，冻结 UUID、采集时间、作品数据和原图/评论选项。重试沿用同一个目录，不再每次产生新 UUID，也不因某张图下载失败而删除已经确认完整的其它资源。

完整作品数据和评论树以检查点冻结。每个图、头像、贴图、JSON 文件以来源身份、相对路径、长度和 SHA-256 保存回执；并行资源通过串行检查点避免互相覆盖。重放先核对已落盘资源，内容改变或缺失才重新获取。动图帧目录保存完整文件集合回执，已完成的离线动图不必再次启动播放 pipeline。

详情、评论和每个回复 API 请求分别领取 NETWORK；缓存复制、写入和摘要核对领取 COPY。最终 manifest 通过 COPY 和父任务最终提交门写入，再更新现有 SnapshotIndex。进程在 manifest 写完与父任务确认之间退出时，可核对全部资源并离线复用该快照。

已完成产物沿用现有 manifest/assets/illust/comments 格式及 UUID 根目录。失败保留可重试内容；取消清理该父任务未发布的目录，已有 manifest 的可见快照保留。输出文件与 SQLite 并非同一原子事务，取消与已落盘输出的跨进程对账仍需最终统一恢复验收。

自动快照冷恢复服从下载策略；显式手动许可限定到本作品及选项。普通缩略图/小说阅读不受父任务影响。已有清缓存的动图读取保护也覆盖快照复制阶段。

归档导出、导入、自动快照转正、配额清理等管理操作仍在后续迁移范围。这里仅说明生成父任务，不代表全部下载迁移完成。
