# Beta 14 → Beta 15 下载迁移对比

Beta 14 已留档：[发布页](https://github.com/Jerry-Ye0vo/Pixiv-Shaft-beta/releases/tag/v4.9.9-beta.14)。Beta 15 延续 ceui.pixiv.pshaft.beta 与固定 Beta 签名；可与官方包并行安装。版本及发布配置在独立提交中更新。

| 范围 | 迁移后的行为 |
| --- | --- |
| 原图、单页/多页、批量下载 | 共享源缓存与队列许可，先入队再执行；保留快捷选择多页、旧队列记录和实际已下载 P 数。 |
| 动图、选帧、剪辑与图片衍生输出 | 父任务持久化请求，原料捕获、编码和最终发布分阶段；共享与保存保留原入口。 |
| 小说单篇/系列/跨系列 | 内容、章节进度和目标冻结；组任务可恢复、选格式、停止抓取并保存已有章节。 |
| 离线快照及管理操作 | 资源下载、导入/导出、升级和清理纳入父任务与资源租约。 |
| 模型、阅读字体、APK | 复用统一物理调度；保留原有模型目录、字体标识与 APK 恢复记录。 |
| 备份、说明和链接导出 | 最终输出进入持久化任务；最终文件/URI 回执校验，失败不伪报完成。 |
| 管理 UI | 复用批量 / 正在 / 已完成页面与原生组件；增加其它内容任务控制和最近记录，隐藏内部子任务重复项。 |
| 调度 | 全局并发、资源互斥、预览/保存/后台优先级与等待老化；停止后等待实际 worker/socket 退出再释放许可。 |
| 兼容 | 原 Room 图库/查重/历史 schema 不重建；统一队列独立数据库做增量升级；按原键写回完成记录。 |

## I/O 范围

扫描基线 3ed17bd458a00470509f3a4008fb608e59c8e9eb 得到 106 个字节 I/O 匹配、60 个文件。这些是调用位置，不能当作 106 个独立下载器。主要分类：

- 用户主动保存/共享/导出、原图源传输、离线快照和模型/字体/APK 资源：已按上表进入持久化任务或共享物理队列。
- 普通缩略图、阅读请求、元数据 API、聊天表情展示缓存：保留交互体验；表情包字节下载/解压接入后台 NETWORK/COPY 许可，展示请求本身不伪装为用户下载任务。
- Muzei 展示流：接共享源传输，读流关闭才释放缓存引用；4xx 继续遵守 Muzei 移除失效作品的语义。
- AI 编辑中间文件、临时渲染缓冲、内置资源复制、日志及数据库读写：属于原功能工作数据；最终用户导出走统一发布流程。
- saveToDownloadsScopedStorage 旧同步兼容方法当前没有调用方，标注仅 worker 线程使用；保留入口以维持兼容。

## 已知边界与性能取舍

- Android 文档提供器创建文件到 URI 回执持久化之间不能保证跨 SQLite 的绝对原子性；恢复会核对已有回执/内容，不声称所有提供器严格 exactly-once。
- 旧任意回调导出在输入捕获完成前被杀进程，无法重建回调：任务显示失败并提示重新生成；捕获后的输入可恢复。
- 独立图片保存与共享可能重复编码；选帧组会额外捕获私有输入，增加临时空间与 I/O，以换取进程恢复能力。
- 正常 Glide 预览缓存、普通阅读和 API 请求保留原生命周期；不是所有 HTTP 请求都变成可见下载任务。
- 未做 K80 Ultra 实机、极慢网络、SAF 提供器异常、满盘及长时间后台性能测量。历史日志没有 ANR trace，不能据此断言原卡顿根因已被实机证实消除。
