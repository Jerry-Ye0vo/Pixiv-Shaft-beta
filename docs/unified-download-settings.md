# 下载设置与统一队列

发布范围：Beta 15。统一持久化用户下载意图和物理 NETWORK / COPY / ENCODE 资源许可；保留旧图库、下载完成记录与查重数据库。

| 设置 | 生效方式 | 边界 |
| --- | --- | --- |
| 自动下载 / 仅 Wi-Fi / 不自动下载 | 修改后立即重新评估可运行任务；冷恢复也遵守限制 | 手动继续仅放行指定任务；明确暂停的任务不会被网络恢复唤醒。仅 Wi-Fi 离开 Wi-Fi 会收回手动网络放行。 |
| 最大同时下载数 | 实时通知共享调度器，NETWORK / COPY 采用设置值 | ENCODE 为 1；降低上限等待已运行任务释放，不强行中断。 |
| 默认图片清晰度 | 新加入的图片任务按设置选 URL | 已修复旧大图详情页保存入口固定使用原图的问题。 |
| GIF / MP4 | 入队时冻结格式；编码失败沿用原有降级语义 | 最终扩展名与 MIME 跟随实际输出。剪辑导出采用剪辑页所选格式。 |
| 命名模板、目录、存储位置、覆盖策略 | 入队时冻结，修改影响之后的新任务 | 分类别覆盖优先于全局默认；本地备份沿用重命名策略。已有任务不会在恢复时悄悄换目的地。 |
| 小说文件格式、头部和章节命名 | 入队时冻结；缺少格式选择的组任务等待用户确认 | 普通阅读不进用户下载队列。 |
| EXIF、说明文本和下载提示 | 仍由原有保存/提示入口处理 | EXIF 适用于支持的图片格式；提示按原有种类开关；不把图片选项强加给 APK/字体/备份。 |
| aria2 | 沿用原有远程派发分支 | 本地队列管理远程请求，不把远程下载误记为已在本机落盘。 |

设置修复复用既有调度唤醒、网络限制和任务恢复机制，没有为每个 getter 或每个入口增加重复测试。
