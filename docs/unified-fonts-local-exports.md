# 字体与通用本地导出

阅读器显式下载字体现在保存字体 ID、固定 URL、字节数和 SHA-256，再依次经过 NETWORK、校验与 COPY 原子替换。保留 `noBackupFilesDir/reader_fonts/<id>.ttf`、Google Fonts 固定版本和原有设置回调。取消等待真实请求退出；删除作为同字体的后继任务，旧请求不能删新文件。坏校验不会破坏已安装字体，原面板只观察父任务，统一管理页可继续、暂停或取消。

下载链接文本、兼容小说文本辅助接口，以及 AI/翻译等现有图片文件保存，统一使用冻结文本/文件父任务和收据发布。首图分享复用可恢复的原始字节准备流程，不经过重编码。普通图片编辑预览、AI 推理中间文件、缩略图缓存和正常阅读的临时数据仍由各自使用流程管理，不作为用户下载记录。

字体专项覆盖共享池等待、哈希安装、坏包保留旧字体、本地命中无网络、停滞 socket 与删除后继、原目录兼容。通用文本/文件沿用已有 LocalOutputs 的恢复、源锁定与提供者故障测试。兼容同步布尔返回接口保留同步语义，只应由既有 IO 调用方使用。
