# 动图选帧与片段导出

保存/分享所选原帧先持久化整批索引、实际源帧路径、时间间隔与冻结目标。协调任务组不占普通任务或物理名额，先在缓存读租约内把原帧复制到自有输入，释放租约后逐个派发输出子任务。暂停/取消只作用于自己的子任务，并等待正在写入的子任务实际完成或停止；重放复用已提交子任务，避免一帧保存两次。

片段 GIF/MP4 是独立持久化父任务。源帧准备位于 COPY，GIF 编码位于 ENCODE，MP4 复用现有硬件编码闸门与统一 ENCODE 入口，最后统一 COPY 发布。设备不支持 MP4 时保留 GIF 回退，文件名与 MIME 跟实际格式。页内播放、时间轴缩略图与编辑预览继续沿用原实现。

分享文件放到独立 FileProvider 子目录，离开页面不取消已接受的准备任务。离线帧失效时明确失败，不把另一套网络帧当作离线原帧；在线缓存失效时可由原帧加载器重新准备。旧作品已下载 P 数和查重记录不把这些派生帧算成原作品页。

专项覆盖整批持久化、原帧字节和顺序、独立分享、GIF 时间间隔、MP4 与 GIF 回退、发布重试复用编码、子任务提交与父任务确认之间暂停、离线源缺失。实际 MediaCodec/图像成品和缓存清理并发仍列入最终设备检查。
