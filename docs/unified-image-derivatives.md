# 海报、滤镜与壁纸准备

这些入口先持久化作品、页码、源地址、滤镜参数和两种实际格式的目标名称/位置/覆盖策略。源图优先复用下载记录或现有文件，缺失时加入共享源队列；复制到任务自有输入后才进入编码。海报的头像提前获取，编码名额内不等待网络。预览编辑不进入持久化导出队列。

海报 Canvas/JPEG 与滤镜全图解码/native 渲染/PNG/JPEG 位于 ENCODE，最终文件发布位于 COPY，具有 URI、长度、SHA-256 收据。分享与壁纸裁剪只暴露已准备好的独立 FileProvider 文件，不清空其他正在分享的文件。系统壁纸裁剪与确认仍由当前页面交给系统处理。

页面销毁只停止观察，已接受的导出继续。编码失败重试使用冻结输入，提供者失败重试复用已经编码的文件；暂停/取消/恢复和最近记录进入统一管理页。旧 `_share`、`_filter_<参数>` 命名及透明图 PNG 保持。跨独立保存/分享操作暂不复用旧 ViewModel 的全图位图缓存，可能重复一次编码；不影响已完成文件和导出参数。

专项覆盖真实队列/SQLite/文件与注入编码器的边界：并发数 1、ENCODE 等待取消、输入冻结、发布重试、PNG 格式、分享文件保留、壁纸零编码、观察者退出。实际 Canvas/native 成像由现有设备测试覆盖，新增路径仍须真机验证视觉结果。
