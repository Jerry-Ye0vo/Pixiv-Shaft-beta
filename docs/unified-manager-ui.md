# 下载管理统一入口

保留「批量－正在－已完成」及原多页快捷选择入口。正在页沿用原生下载卡片，补充小说、小说任务组、模型、离线快照、简介/备份、翻译图片和应用更新。各物理阶段不重复显示为用户任务；合集只显示父任务，批量动图沿用原批量行。

任务卡和顶栏暂停、继续、重试、清空均转发给对应进程所有者，不因关闭页面而取消。等待格式确认的小说提供明确的格式选择操作；全部继续不替用户选择格式。复制已进入不可中断的最终写入时，接受的停止不得虚假宣称已经生效；安装包暂停等待网络流和分片实际退出。

已完成作品页继续使用原图片历史和实际 P 数。其他任务的最近凭据从「最近任务」查看，不混进作品页数、不改旧查重数据库。界面复用下载卡片与 WitDialog，暂停和取消触控区扩大到 48dp，长标题与失败原因允许换行。

专项测试验证父子/批量去重、活跃统计、全局暂停/继续/失败重试方向、停止确认状态、复制暂停续传/取消及 APK 停止范围。深浅主题、窄屏/大字体实机视觉检查、通知后台保活和 K80 Ultra 压力测试仍须单独执行并在发布报告中标明。
