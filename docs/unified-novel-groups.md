# 可恢复的小说系列任务组

单系列合并、跨系列分别合并、全系列合成一份都先保存 `novel-series-group` 请求。请求冻结系列顺序、格式、命名模板、下载日期、目标位置和覆盖策略。章节列表与已抓正文逐步保存，离开页面只停止观察，不取消任务。

任务组与普通输出任务分别限制协调并发；二者均不占 NETWORK/COPY/ENCODE 名额。每次 API 请求才申请 NETWORK，限流等待和格式确认均在物理资源池外。即使普通任务并发数为 1，任务组仍可等待自己的输出子任务。

`content_queue.db` 从版本 1/2 增量升级到 3，保留全部旧物理任务与父任务，新增控制表和子任务归属表。原下载 Room 数据库、作品已下载数量、查重键与历史格式不变。

停止抓取写成截短合集的控制单独持久化，不与章节检查点互相覆盖。需要确认插图格式时，任务保存章节后暂停；页面仍在时沿用原确认回调，离开页面后保留暂停任务。已成功输出的子任务按任务组与输出位置复用，避免“输出完成但组检查点未写入”导致重复导出。冷启动时，暂停或取消的任务组不能派发其子任务。

专项测试覆盖并发数 1、章节顺序、部分停止、跨系列独立输出/全合并、坏章节、全部失败、检查点恢复、暂停续传、冻结命名、版本 1/2 升级和组/子任务归属。真机格式交互、SAF 权限撤销和性能测量列入发布前人工清单，不能以单元测试代替。
