# 中断窗口的产物确认

文件系统、SAF/MediaStore 与 SQLite 不能组成一个跨存储的原子事务。队列会先保存目标 URI、输入长度和 SHA-256，再写入并发布文件，最后确认父任务。进程在两者之间退出时，不能仅凭数据库状态重建第二份文件。

恢复或取消未确认的任务时，小说、动图和本地导出校验精确 URI 的字节数与哈希，补齐发布和原有历史记录后确认完成。模型校验带计划身份的安装收据和全部必需文件；快照校验冻结清单与全部资源；快照导入验证完整文件集合，推广和删除核实已完成的目录效果。任务组保留子输出归属和已完成凭据。

只校验已有产物，不为了响应取消创建新文件。字节被修改、文件缺失或不属于本任务时不宣称完成。提供者权限等导致校验异常时保留输入和收据，显示失败供恢复权限后重试。模型删除仍保留备份直到数据库确认，未确认的取消可以回滚。

专项覆盖历史写入失败后取消、产物被修改、冷启动取消收据重核验，以及权限失败时不删除恢复输入。此协议缩小重复窗口，不能宣称所有提供者严格 exactly-once；创建文档到保存 URI 之间仍可能有不可检索的孤立文档。
